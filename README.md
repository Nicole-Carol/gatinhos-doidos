# 🐱 Gatinhos Doidos

Um pequeno projeto desenvolvido com HTML, CSS e JavaScript sobre gatos famosos.

## 🐾 Sobre o projeto

O site apresenta alguns gatos que ficaram conhecidos por histórias curiosas e permite que o visitante conheça um pouco mais sobre cada um deles.

Atualmente, o projeto apresenta:

- 🐱 Stubbs
- 🐱 Tama
- 📖 Informações sobre cada gato
- 🖼️ Imagens
- ✨ Interação com JavaScript
- 📱 Layout adaptável para diferentes telas

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Este projeto foi desenvolvido como forma de praticar os fundamentos de desenvolvimento web, principalmente:

- Estrutura HTML
- Estilização com CSS
- Eventos em JavaScript
- Manipulação do DOM
- Organização de arquivos
- Publicação de um site na internet

## 🚀 Projeto

O site está sendo desenvolvido como um projeto de aprendizado e poderá receber novas funcionalidades futuramente.
